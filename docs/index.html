solana-ws-keepalive

Solana WebSocket subscriptions that stay alive

Detects a feed that has gone silent while the socket still looks open, reconnects with backoff, and puts every subscription back. Zero dependencies.

View on GitHubStart trading on BlixJoin the Discord

Try it

npx github:blixvip/solana-ws-keepalive slots

What it does

  • Dead-feed detection by silence
  • Reconnect with backoff and jitter
  • Automatic resubscribe after every reconnect
  • A heartbeat for quiet subscriptions

Use it in your code

npm install github:blixvip/solana-ws-keepalive
import { createStream } from "solana-ws-keepalive";

const stream = createStream({ url, heartbeat: true });
stream.subscribe("logsSubscribe", [{ mentions: [address] }], console.log);

Full documentation, the API and the FAQ are in the README. It is MIT licensed and has no dependencies.
