# Code of conduct

Be useful and be decent. In issues, pull requests and the Discord:

- Criticise code, not people.
- No harassment, slurs, or personal attacks. No shilling coins, no referral links, no asking people for funds or keys.
- Assume the person asking a basic question is new, not lazy.

Maintainers may edit or remove comments and block accounts that ignore this. To report a problem, message a maintainer in the Discord: https://discord.gg/grokbot

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
